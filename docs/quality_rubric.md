# Summary and quiz quality — D17

D15 asked whether the content is correct. This asks how good it is, on a scale,
so the report can quote a number rather than an impression.

Score every item 1 to 5. Review at least six modules; use the same modules for
summaries and quizzes so the two scores are comparable.

- 5 — nothing to change
- 4 — minor wording
- 3 — usable but a student would notice the problem
- 2 — needs rewriting before use
- 1 — wrong or unusable
